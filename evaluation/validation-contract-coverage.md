## Phase 2 exit assessment

The real Draft 2020-12 library, schema checker, top-level runner and CI
workflow are implemented. The validator contract itself is not complete:
rule 12 is open, and all other numbered items have bounded gaps above.
The matrix makes these gaps visible instead of treating a passing sample as a
conformance result. Phase 2 remains open until each mechanical gap has
positive/negative/boundary coverage and the remaining judgment/history rules
have a justified disposition under the Core and required human checkpoints.

The GitHub Actions workflow uploads the runner's JSON report with revision,
dirty-state, Python version, per-suite results, and workflow identifiers.
This is configuration evidence only until the workflow executes on a hosted
runner at an exact revision and the artifact is retrievable (E3).
