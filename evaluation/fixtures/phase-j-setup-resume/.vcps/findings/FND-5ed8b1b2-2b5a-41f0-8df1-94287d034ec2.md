## No CI, discovered during RESUME

This project (`Synthetic Commerce Evaluation Fixture`, `L3`) has no
hosted CI. `ci.present: false` was already recorded in `project.yaml`
when this setup resume began; this finding formalizes that fact as a
legacy `EVIDENCE_GAP` per `VCPS-SETUP-022`, since Stage 9 had not yet
run before this resume.

Severity is rated `HIGH`, not the `LOW`/`MEDIUM` seen in lower-level
fixtures, because `VCPS-LVL-010` is explicit that an `L3` project may
only substitute `E2 LOCAL` for `E3 CI` if the gap is recorded with an
owner, and any gate relying on it **MUST NOT exceed `PARTIAL`** — this
is a real, binding ceiling on every gate in this project until either a
real CI pipeline exists or this finding is explicitly risk-accepted by
the project owner (`HC-08`), which has not happened. Recorded as a
legacy `EVIDENCE_GAP` rather than fixed during setup (`VCPS-SETUP-025`:
creating CI pipelines is an adapter/implementation concern, not a Setup
